# Skins do Adelino (Instagram)

O robô do Instagram troca o Adelino de acordo com o post. Basta salvar aqui um PNG **com fundo transparente**, de cerca de 1000 px, com o nome do tema:

| Arquivo | Quando aparece |
|---|---|
| `terror.png`, `rpg.png`, `fps.png`, `luta.png`, `esportes.png`, `estrategia.png`, `aventura.png`, `acao.png`, `indies.png`, `simulacao.png`, `musica.png`, `arcade.png`, `mobile.png` | Notícia, promoção ou enquete de um jogo dessa categoria |
| `urgente.png` | Notícia urgente |
| `meme.png` | Meme da comunidade |
| `enquete.png` | Enquete sem categoria |
| `promocao.png` | Promoção do dia |
| `resumo.png` | Capa do resumo do dia |
| `noticia.png` | Notícia sem categoria |

Para variar, numere: `terror-2.png`, `terror-3.png`... O robô sorteia uma delas.
Sem skin para o tema, ele usa o Adelino padrão (`img/Adelino.png`).
